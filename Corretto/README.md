# Amazon Corretto 25 JDK

Download **Amazon Corretto 25** (Windows x64 JDK) from:
https://aws.amazon.com/corretto/

Either:
- Extract the portable JDK archive into this folder (e.g., `Corretto\jdk25.0.5_0\bin\java.exe`), **or**
- Install the `.msi` system-wide into `C:\Program Files\Amazon Corretto\`.

The scripts in `..\scripts\` automatically detect either location.
